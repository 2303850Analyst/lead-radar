# Подключение 2GIS Places API и MapGL

2GIS подключается как серверный источник организаций и как движок встроенных
карт. Ключ Places остаётся серверным. MapGL по своей природе получает ключ в
браузере, поэтому для production нужен отдельный ключ с доступом только к Map
Tiles и ограничением разрешённых доменов. Ни один ключ не должен попадать в Git,
логи или скриншоты.

## 1. Настройка ключа

Создайте или откройте `.env.local` в корне проекта:

```env
DGIS_API_KEY=ваш_серверный_ключ
DGIS_MAP_KEY=ваш_ограниченный_ключ_map_tiles
DGIS_DEMO_MODE=true
DGIS_CONTACTS_ENABLED=false
DGIS_EXPORT_ENABLED=false
SEARCH_PROVIDER=2gis
```

- `DGIS_DEMO_MODE=true` включает ограничения demo-подписки.
- `DGIS_MAP_KEY` используется двумя встроенными картами 2GIS MapGL. Для
  локальной проверки при пустом значении приложение использует
  `DGIS_API_KEY`, однако этот fallback делает ключ видимым браузеру и не
  подходит для внешнего deployment.
- `DGIS_CONTACTS_ENABLED=false` фиксирует, что отдельное право на контактные
  поля не подтверждено: адаптер не запрашивает `contact_groups`, а отсутствие
  телефона или сайта не считает цифровым разрывом. Меняйте значение на `true`
  только после явного разрешения этих полей для ключа.
- `DGIS_EXPORT_ENABLED=true` разрешает CSV нормализованной выдачи только при
  наличии отдельного права на сохранение/экспорт. Этот флаг не включает
  localStorage, не сохраняет raw-ответы и не меняет доступность контактных полей.
- `SEARCH_PROVIDER=2gis` выбирает 2GIS для поиска организаций. Значения
  `geoapify` и `demo` сохраняются для явного переключения источника.

Текущая alpha-интеграция переиспользует Geoapify Geocoding для преобразования
введённого адреса в координаты, поэтому оставьте настроенный
`GEOAPIFY_API_KEY`. Если пользователь выбрал точку непосредственно на карте,
поиск 2GIS получает уже готовый центр.

После изменения окружения полностью перезапустите сервер:

```powershell
npm run build
npm run start
```

Официальные страницы: [Platform Manager](https://platform.2gis.ru/),
[тарифы и demo](https://docs.2gis.com/en/platform-manager/subscription/pricing),
[Places API](https://docs.2gis.com/en/api/search/places/overview),
[MapGL](https://docs.2gis.com/en/mapgl/start/first-steps).

## 2. Цепочка поиска

Для однозначного физического бизнеса сервер выполняет bounded-цепочку:

1. Query Intelligence возвращает provider-neutral тип бизнеса, синонимы и
   дополнительные требования.
2. Сервер собирает исполнимый план и передаёт в адаптер 2GIS свободный текст,
   центр, радиус и лимит. Kimi не задаёт endpoint, координаты или 2GIS IDs.
3. Адаптер выполняет до трёх ограниченных free-text запросов к
   `https://catalog.api.2gis.com/3.0/items` по основному типу и синонимам. Каждый
   запрос получает `type=branch`, `q`, `point`/`location`, радиус не более
   50 км и в demo-режиме `page_size` не более 10.
4. Карточки нормализуются в общий контракт LeadRadar, дедуплицируются и
   проверяются на соответствие исходному типу бизнеса.
5. Пустой валидный ответ становится `success_empty`; ошибка ключа, лимита или
   транспорта остаётся контролируемой технической ошибкой.

Свободный `q` не требует заранее добавленного alias или `rubric_id`. Широкая
рубрика сама по себе не подтверждает точное соответствие: сервер использует
название и рубрики карточки как evidence, а слабые совпадения помечает как
возможные или отклоняет.

## 3. Данные и ограничения demo

По умолчанию 2GIS имеет policy `contract_required`:

- результат можно посмотреть в текущем экране;
- LeadRadar не сохраняет его в `localStorage`;
- кнопка постоянного локального хранения отключена;
- CSV отключён, пока сервер явно не получил `DGIS_EXPORT_ENABLED=true`;
- raw-ответ 2GIS не сохраняется;
- атрибуция 2GIS остаётся видимой на экране результата.

Личное или исследовательское использование не отменяет условия конкретной
подписки. `DGIS_CONTACTS_ENABLED=true` означает лишь технический доступ к
полям. При подтверждённом праве на выгрузку можно отдельно включить
`DGIS_EXPORT_ENABLED=true`, не разрешая браузерное хранение всей выборки.

Этаж и тип здания проверяются только по явно полученным полям карточки. Если
данных нет, условие получает `unknown`, а не автоматически считается
совпавшим.

## 4. Быстрая проверка

1. Откройте `http://127.0.0.1:3000`.
2. Выполните поиск `кальянная` в радиусе от выбранного центра.
3. На результате проверьте подпись `Источник: 2GIS Places API`. При
   `DGIS_EXPORT_ENABLED=true` CSV доступен, а постоянное хранение остаётся
   отключённым.
4. Повторите с заранее неизвестным физическим бизнесом: запрос должен дойти до
   2GIS и вернуть результат либо честный `success_empty`, но не
   `NO_SUPPORTED_CONCEPT`.

Если сервер сообщает об ошибке авторизации поиска, проверьте `DGIS_API_KEY` и
доступ Places API. Если не загружается карта, проверьте `DGIS_MAP_KEY`, доступ
Map Tiles и разрешённый origin. После изменения `.env.local` полностью
перезапустите процесс. Не вставляйте ключ непосредственно в компоненты и не
добавляйте префикс `NEXT_PUBLIC_`: ключ передаётся MapGL из server-render.
