## Воспроизводимые команды

```powershell
npm run quality

$env:RUN_KIMI_LIVE_EVAL = "1"
$env:KIMI_INPUT_USD_PER_MILLION = "3"
$env:KIMI_OUTPUT_USD_PER_MILLION = "15"
.\scripts\run-with-kimi-secret.ps1 -NpmScript "eval:kimi:live"

.\scripts\run-with-kimi-secret.ps1 -NpmScript "start"
npm run smoke:stream
```

Wrapper читает ключ из внешнего `%USERPROFILE%\.sa-trainer-secrets\kimi.env`
и передаёт его только процессу сервера. Live-evaluator пишет детальный
санитизированный отчёт в игнорируемый `work/evaluations/`; этот файл не является
частью репозитория.

## Сквозной поиск Kimi → Geoapify

Production-сервер был поднят на `127.0.0.1:3000`; `npm run smoke:stream`
отправил естественный zero-token-overlap запрос про уход за бородой. Результат:

- HTTP 200 и terminal event `result`;
- этапы `validation`, `intent_resolution`, `provider_compilation`, `geocoding`,
  `places`, `details`, `normalizing`, `complete`;
- Kimi выбрал `personal_care.barbershop`, `cacheHit=false`;
- Geoapify вернул 100 карточек, нормализовано 95 лидов;
- 18 лидов имели URL сайта, 16 — телефон;
- `rawResponsesStored=false`.

Отдельный confirmation-smoke подтвердил, что «склад» не обращается к POI до
выбора пользователя; после подтверждения `logistics.warehouse` сервер выпустил
план `user_confirmed` и вернул два реальных результата Geoapify.

до production-релиза.

## Quality-gate решение

| Gate | Статус | Основание |
|---|---|---|
| Allowlisted provider selectors | PASS | 0 нарушений в offline и live paths |
| Strict Structured Output | PASS initial | 5/5 live, fault suite зелёный |
| CIS initial semantics | PASS initial | RU/BY/KZ обычные кейсы корректны |
| Ambiguity safety | PASS initial | «склад» требует подтверждения |
| Unsupported safety | PASS initial | облачная CRM не запускает POI |
| Planner p95 ≤ 20 с | Наблюдаемо PASS | 4,695 с на n=5; выборка недостаточна для SLO |
| Input ≤ 3000 tokens/call | FAIL | 4 из 5 вызовов выше цели либо около неё; максимум 4127 |
| 500/600 frozen datasets | FAIL | 222/60 |
| 100 live intents/model и stability 30×3 | NOT RUN | production gate |
| Runtime relevance classifier | N/A | намеренно не реализован до data-flow gate |
| Auth, limiter, scheduler, deadline, circuit breaker | FAIL | локальный alpha |

## Итог

Сервис технически работает локально на реальном Kimi и реальном Geoapify,
обрабатывает нормальные CIS-формулировки, безопасно останавливает неоднозначные
и неподдерживаемые запросы и имеет воспроизводимый test/eval workflow.

Production `v0.4.0` выпускать нельзя до расширения выборок, оптимизации prompt,
нагрузочных и длительных измерений, завершения server orchestration, auth/quota
защиты и отдельного решения по post-search classifier. До этого допустимое
обещание пользователю — best-effort локальный сервис с terminal deadline 60 с,
а не договорный SLA.
