Нарушения open-vocabulary request, server-owned geography, compiler safety,
provider grounding, cache/version identity, согласованности разметки и
целостности корпуса: **0**.

Двадцать hidden physical families используют по четыре вручную заданных
semantic-описания без token overlap с provider category ID. Поэтому exact
category coverage намеренно ниже 1.0: для таких запросов gate принимает
ограниченный server-owned name fallback как исполнимую стратегию, но не выдаёт
его за точное категорийное совпадение. Проверка всех 80 hidden-вариантов не
может быть заменена одним alias или legacy binding.

Здесь `holdout` означает evaluation-only split внутри приватного репозитория:
его 80 сценариев не используются для построения production matcher и обязаны
проходить отдельный gate на 100%. Это не криптографически секретный внешний
benchmark; для такой независимости потребуется закрытый CI-артефакт и отдельное
управление ключом/доступом.

## Воспроизведение

```powershell
npm run eval:open-world
```

Команда завершает процесс ненулевым кодом при нарушении coverage, quality или
zero-tolerance gate. Она использует golden mock Kimi и фактический
`createSearchPlan`/Geoapify compiler. Поэтому PASS доказывает корректность
локальной orchestration и компиляции для размеченного корпуса, но не измеряет
качество, latency или стоимость live Kimi. Production по-прежнему блокируют
600-case relevance/classifier gate, live model evaluation, browser/load tests,
auth и shared admission/quota control.
