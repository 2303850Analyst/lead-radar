N/A; NO-GO для production v0.4.0**.

Корпус содержит 600 явно размеченных синтетических карточек по 150 provider
targets. Retrieval-контекст, evidence и expected outcome зафиксированы

## Воспроизведение и границы вывода

```powershell
npm run eval:relevance
```

Команда использует фактические `classifyCandidateRelevance` и
`validateCandidateRelevance`, печатает только агрегаты и возвращает ненулевой
exit code при нарушении gate. Optional Kimi-classifier по умолчанию выключен:
реальные карточки модели не передаются, а AI precision/recall честно имеют
статус `N/A`. PASS не является оценкой live Kimi и не снимает требования auth,
shared quota/admission, browser/load и live model gates.
